---
title: What changed in these docs
---

These docs were reorganised and updated for MapRoulette 4. If you have read them before, or have links saved, this page summarises what moved and what went away.

## URLs

Pages no longer have a language segment in their address:

```
old:  /en-US/documentation/your-dashboard/
new:  /documentation/your-dashboard/
```

Old `/en-US/` links redirect to the new address, so saved links still work.

## Sections

| Old section | Pages moved to |
|:------------|:---------------|
| Basics | Getting Started, Mapping Tasks, User Settings, Challenges, Advanced |
| Advanced Topics | Mapping Tasks, Advanced |
| Creating and Managing Challenges | Challenges, Tasks, User Settings |
| New Topics/Features | Mapping Tasks, User Settings, Challenges, Tasks |
| Working as a Team | Projects and Teams |
| Server Admin | Server Admin |

## Removed pages

These pages describe features that aren't in MapRoulette 4, and their old links will 404:

- Virtual Challenges
- Using Mapillary Images
- Using Layouts
- Cooperative Challenges (the Tag Fix part moved to [Tag Fix Challenges](/documentation/tag-fix-challenges/))
- Following other Users
- Virtual Projects
- Reviewing (only available through a review plugin)
- MapRoulette Tags
- Help Us Translate Our Documentation

## Renamed pages

- Rapid Editor is now [Editing inside MapRoulette](/documentation/id-editor/). Old links redirect.
- Challenge Flagging is now [Filing a Challenge Report](/documentation/challenge-flagging/).

## New pages

- [Moving from MapRoulette 3 to MapRoulette 4](/documentation/maproulette-3-to-4/)
- [Runtime Configuration](/documentation/runtime-configuration/)
- [Super Admin](/documentation/super-admin/)

## Translations

The German, Spanish, French, Dutch, Russian and Portuguese translations were removed. They covered only a few pages and had fallen out of date. The docs are English only for now.
