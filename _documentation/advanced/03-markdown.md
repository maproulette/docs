---
title: Styling Text with Markdown
---

MapRoulette supports a variant of Markdown for marking up or styling text. Markdown can be used in most places where long-form text can be entered, such as task comments, challenge descriptions, challenge instructions, etc.

The variant supported by MapRoulette is [CommonMark](https://commonmark.org/), so headings, bold and italic text, links, lists, code, block quotes and images all work. A single newline is shown as a line break. Raw HTML and [GitHub-flavored](https://help.github.com/en/github/writing-on-github/basic-writing-and-formatting-syntax) extensions such as tables, strikethrough and task lists are not supported.
