---
title: Searchbox Short-Commands
---

The search box in the header supports short-commands that can be used to quickly search for data in maproulette.

## List of Supported Commands:

`c:` Search by challenge name

`p:` Search by project name

`t:` Search for a task by ID

`id:` Search for any project, challenge or task with that ID

`f:` Search projects, challenges and tasks together

`tc:` Search task comments

`cc:` Search challenge comments

To find challenges in a geographic area, use the location filter on [Explore Challenges](/documentation/discovering-challenges/).
