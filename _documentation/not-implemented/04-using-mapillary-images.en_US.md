---
title: Using Mapillary Images
---

> Mapillary imagery is not available in the current MapRoulette frontend. The
> integration described below was part of an earlier version, and is documented
> here for reference until it returns.
{: .legacy}

The Mapillary integration showed Mapillary image locations relevant to the task
location, using the native Mapillary viewer widgets, so you could zoom in and
easily skip to the next or previous images in a Mapillary sequence.

![](/media/mapillary-integration.png)

In the meantime, the **OSM** tab in the task panel links out to
OpenStreetMap, OSMCha and Overpass Turbo for the task's location, and street
level imagery can be consulted in [Mapillary](https://www.mapillary.com/) or
[KartaView](https://kartaview.org/) directly.
